### Initiator confirmation — 16 September 2026

The following confirmations apply to all nine runs. Evidence status: **confirmed retrospectively by initiator**, not independently verified execution logs.

- The same three attachments and fixed prompt were used for all runs. Historical file-byte identity has not been independently verified.
- Each run began in a new conversation, without sharing other models' answers. This does not establish that account-level memory or other persistent context was disabled.
- The first answers were copied unchanged into Word, without retries or abridgment. Original service transcripts have not been independently compared.
- The initiator recalls that web-search availability was probably left enabled. Exact settings and actual search activity remain unverified.

**Planned versus actual conditions:** The original instructions prohibited web research. Search availability may nevertheless have remained enabled. Availability does not prove that searches occurred, but these cannot be described as verified browsing-disabled runs. If external retrieval occurred, the information available could differ between runs. Preserve this uncertainty without rewriting the original plan.

Execution dates, exact service interfaces and screen labels remain unverified. Future confirmations should state their date and basis. A rerun is a new run, not replacement evidence for a historical execution.

This manifest documents the pilot; it does not establish independent verification of the historical runs. The source Word document remains local and is not included in this publication.
